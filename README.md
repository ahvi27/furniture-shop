# Haven — Furniture shop

A responsive furniture storefront served with Python. No packages required.

## Start
1. Extract this ZIP.
2. Open a terminal inside the furniture-shop folder.
3. Run: python3 app.py
4. Open http://localhost:8000

On Windows, use python app.py if python3 is unavailable.
To use another port: python3 app.py --port 8080

Includes search, category filters, sorting, and a shopping cart saved in your
browser. Prices are illustrative USD values. This is a demo storefront:
no payments are taken and no orders are submitted. All illustrations are
included locally; the website needs no internet connection to display.

Edit the products in static/app.js, styling in static/style.css,
and page content in static/index.html.
